# guzus/homebrew-tap

Homebrew formulae for [guzus](https://github.com/guzus) tools.

```bash
brew install guzus/tap/birdy
```

Homebrew expands `guzus/tap` to this repository, so the `homebrew-` prefix is
never typed.

## birdy

[birdy](https://github.com/guzus/birdy) is a multi-account X/Twitter CLI that
rotates between stored accounts to spread rate-limit pressure. It ships as a
single Go binary with no Node runtime.

Formulae here are published by goreleaser when birdy is released.
